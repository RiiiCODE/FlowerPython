# 🌹 Pointillism Rose Animation

A beautiful animated rose created with Python using the **pointillism technique** — building an image from many tiny dots.

## ✨ Features

- 🌹 Rose animation made from tiny dots.
- 🎨 Pointillism visual effect.
- 🖥️ Interactive desktop window using Tkinter.
- ⚡ Lightweight Python script.
- 🐍 Easy to run and customize.

## 📋 Requirements

- Python 3.10 or newer recommended.
- NumPy
- Pillow

## 📦 Installation

**1. Clone the repository**

```bash
git clone https://github.com/RiiiCODE/FlowerPython.git
cd FlowerPython
```

**2. Install dependencies**

```bash
python -m pip install numpy Pillow
```

**3. Run the animation**

```bash
python rose.py
```

## ⚙️ Troubleshooting

**ModuleNotFoundError: No module named `numpy`**

```bash
python -m pip install numpy
```

**ModuleNotFoundError: No module named `PIL`**

```bash
python -m pip install Pillow
```

**Tkinter is unavailable**

Tkinter is usually included with standard Python installations. On some Linux systems, it must be installed separately through the system package manager.
